# Satyam Shukla — Portfolio

Responsive, animated portfolio website built from the supplied résumé.

## Run locally

Open `index.html` in a browser, or serve this folder with:

```powershell
python -m http.server 8765
```

Then visit `http://localhost:8765`.

## Included

- Animated landing section, scroll progress, theme switch, and mobile navigation
- Project category filters, detail dialogs, and source links
- Education, skills, certificates, achievements, contact links, and résumé download
- Desktop preview captures as `01-home.png` and `02-github-ecommerce.png`

The Shopper E-Commerce card uses a screenshot captured while running `sat301/e-commerce` locally. The Book Management card is an illustrative UI concept; its source repository is linked from the card. The public repositories use React/Vite and PHP/MySQL, which differ from the résumé's Java/JSP project descriptions.
